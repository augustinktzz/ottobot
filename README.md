# OttoBot

This repository only holds the released versions of OttoBot (formerly MyBot): the Windows installer and the Linux
AppImage, under [Releases](../../releases). The installed application updates itself from here.

## Install

- **Windows**: download `OttoBot-Setup-X.Y.Z.exe` from the latest release and run it.
- **Linux**: download `OttoBot.AppImage` from the latest release, make it executable (`chmod +x`), then run it.

An installed MyBot updates itself to OttoBot: its profiles, settings and activation key are kept.

## Activation

OttoBot needs an activation key. On the first start, the activation window shows the ID of your PC: click **Copy**,
send it to get your key, then paste the key and click **Activate**. A key works on that PC only.
